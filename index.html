Which is which?

A utility meets its load using two heterogeneous plants — one expensive to build but cheap to run, the other cheap to build but expensive to run. This tool identifies which plant should be run as the base load plant and which as the peak load plant, and works out how many hours a year the peaking plant should actually operate.

The problem

The utility must meet a fluctuating annual load using two heterogeneous plants. Plant 1 costs C1 rupees per kW per year to install and R1 paise per kWh to run; Plant 2 costs C2 per kW per year and R2 paise per kWh. Because the two plants trade fixed cost against running cost, the cheapest overall system uses the plant with the higher fixed / lower running cost as the base load plant (running nearly all 8760 hours of the year), and the plant with lower fixed / higher running cost as the peak load plant (running only during the highest hours of demand).

Modelling the annual load duration curve as a straight line and minimising total annual cost with respect to the base/peak switch-over point gives a clean, closed-form answer for how many hours the peaking plant should actually run — it depends only on the cost figures, not on the region's demand or load factor:

OPTIMAL PEAK-PLANT HOURS
t₁ = (Cbase − Cpeak) / (Rpeak − Rbase)
